# 2026_Iceland

冰島旅行回憶與收據整理，圖片核對更新於 2026/10/13。

下載本儲存庫後，開啟 `index.html` 即可離線查看。請保留資料夾結構，以查看完整收據照片及下載 Excel。

- 可點選「與大家均分」或「朱 & Kent 自付」，並搭配商店、日期及幣別篩選。
- 55 筆交易、286 個品項、63 張收據照片。各幣別 ISK／GBP／AED 分開計算。
- 39 個品項及 19 家店附已核對的品牌、店家或 Google Maps 顧客參考圖；來源與限制逐項標示。
- 247 個品項尚未確認同款圖片，保留明細並留白。
- 9/28 Krónan Vík 已歸入與大家均分；票據與分類清單的 100 ISK 差額保留註記。

`旅行收據明細.xlsx` 提供完整表格；CSV 可供匯入。其他待核實金額與模糊內容請見 `核對與限制.txt`。

照片僅作旅行紀錄與品項核對。第三方參考照片的來源及權利屬原作者；來源連結列於頁面與 `參考圖片核對.csv`。
